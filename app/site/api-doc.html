诗笺开放 API

免费查询中国古典诗词与典籍：从先秦到近代，八十余万篇。无需注册，无需密钥，支持跨域调用。

基本信息

地址https://shijian.jisu.cn/api/v1
方法只支持 GET，返回 JSON（UTF-8）
跨域已开启 CORS（Access-Control-Allow-Origin: *），浏览器可直接调用
限流每个 IP 每分钟 60 次，超出返回 429
缓存除随机接口外，CDN 节点缓存 60 天，浏览器缓存 1 天
数据正文来自 chinese-classics，均为公版古籍；接口只提供正文，不含注释与赏析

在线试用

点「请求」看返回结果

接口

GET/api/v1/search

全文检索标题与正文。输入的每段连续汉字须在原文中连续出现（不跨标点），多段之间为「且」关系。单个汉字按前缀匹配。

参数说明
q必填，检索词，如 床前明月光、明月 故乡
in可选，title 只搜标题，content 只搜正文；默认都搜
author可选，作者名精确匹配，如 李白
era可选，朝代分区：先秦、秦汉、魏晋南北朝、隋、唐、五代、宋、辽金、元、明、清、近代
dynasty可选，具体朝代，如 北宋、南宋
kind可选，诗、词、曲、典籍
page / size可选，页码（1–100）与每页条数（1–50，默认 20）
GET /api/v1/search?q=床前明月光&size=1

{
  "query": "床前明月光", "page": 1, "size": 1, "has_more": false,
  "data": [{ "id": 41910, "title": "静夜思", "author": "李白", "author_id": 2692,
             "dynasty": "唐", "era": "唐", "kind": "诗",
             "excerpt": "床前明月光，疑是地上霜。",
             "url": "https://shijian.jisu.cn/api/v1/poems/41910" }]
}

GET/api/v1/poems/{id}

按 id 取一篇作品全文。paragraphs 为分段正文；词有 rhythmic（词牌），典籍有 book（书名）、chapter（篇章）。

{
  "data": { "id": 41910, "title": "静夜思", "author": "李白", "author_id": 2692,
            "dynasty": "唐", "era": "唐", "kind": "诗",
            "paragraphs": ["床前看月光，疑是地上霜。", "举头望山月，低头思故乡。"],
            "url": "https://shijian.jisu.cn/api/v1/poems/41910" }
}

GET/api/v1/random

随机一首，不缓存。可选 era、dynasty、kind 过滤；famous=1 只从唐诗三百首中选。

GET /api/v1/random?kind=词&era=宋

GET/api/v1/authors?q={作者名}

按作者名查找（精确或前缀），按作品数排序。同名不同人会分别列出，可用 dynasty 区分。

{ "query": "李白", "data": [{ "id": 2692, "name": "李白", "dynasty": "唐", "era": "唐", "works": 1649 }] }

GET/api/v1/authors/{id}

作者小传与作品列表（分页，page、size 最大 100）。

{ "data": { "id": 2692, "name": "李白", "dynasty": "唐", "intro": "李白，字太白……", "works": 1649,
            "page": 1, "size": 50, "list": [{ "id": 41910, "title": "静夜思", "kind": "诗" }] } }

GET/api/v1/stats

收录总数与各朝代、体裁的篇数。

错误

出错时返回对应 HTTP 状态码和：

{ "error": { "code": "rate_limited", "message": "请求过于频繁：每个 IP 每分钟 60 次" } }
状态码code含义
400bad_query / bad_id参数缺失或格式不对
404not_found没有这篇作品或作者
405method_not_allowed只支持 GET
429rate_limited超出限流，稍后再试
502upstream_error数据服务暂时不可用

示例

// JavaScript
const r = await fetch('https://shijian.jisu.cn/api/v1/random?famous=1');
const { data } = await r.json();
console.log(data.title, data.author, data.paragraphs.join(''));

# curl
curl 'https://shijian.jisu.cn/api/v1/search?q=春眠不觉晓'

使用说明

  • 古籍正文为公有领域，可自由使用；欢迎在页面上注明「数据来自诗笺 shijian.jisu.cn」。
  • 作品 id 稳定，可以放心保存引用。
  • 请合理调用，批量需求请缓存结果，不要用于全量抓取。
